# FormantFlex — плагин для смены форманты голоса (VST3 для FL Studio 25)

FormantFlex сдвигает форманты голоса (тембр, «размер» голоса), **не меняя высоту тона**.
Голос можно сделать глубже и мужественнее или светлее и женственнее, а можно получить гиганта или мультяшного персонажа.

## Возможности
- **FORMANT** — большая ручка, от −12 до +12 полутонов с шагом 0.01. Изменения плавные, без щелчков.
- **7 пресетов в один клик**: Giant −9, Deep −5, Warm −2, Natural 0, Bright +2, Light +5, Tiny +9.
- **Живой график огибающей**: серая линия — исходные форманты, оранжевая — сдвинутые.
- **DETAIL** — насколько точно отслеживаются форманты. 50 % подходит почти всегда, меньше — мягче и «чище», больше — чётче и характернее.
- **MIX** — dry/wet с фазовым выравниванием (без «гребёнки»), чтобы смешивать с исходным голосом.
- **OUTPUT** — выходная громкость, от −24 до +12 дБ.
- Подсказка под ручкой («Deeper, more masculine», «Brighter, more feminine» и т. д.).
- Окно можно растягивать. Двойной клик сбрасывает ручку, Ctrl+перетаскивание — точная настройка, по значению можно кликнуть и ввести число.
- Плагин сообщает FL Studio свою задержку (~43 мс), и FL компенсирует её автоматически. В режиме bypass задержка не меняется.
- Работает в моно и стерео, 44.1–192 кГц, все параметры автоматизируются.

## Как это работает
STFT (окно Ханна, перекрытие 75 %). Для каждого кадра оценивается спектральная огибающая итеративным методом *true envelope* (кепстр с порядком, который подстраивается под высоту голоса). Затем огибающая растягивается или сжимается по частоте и применяется как кривая усиления. Гармоники и фазы не трогаются, поэтому высота тона сохраняется.
Нагрузка — около 4–5 % одного ядра на канал.

## Сборка

### Вариант A — без установки чего-либо (GitHub Actions)
1. Создайте репозиторий на GitHub и загрузите туда содержимое этой папки (вместе с `.github`).
2. Откройте вкладку **Actions**. Сборка запустится сама (около 10 минут).
3. Скачайте артефакт **FormantFlex-Windows-VST3** (для macOS — **FormantFlex-macOS-VST3-AU**).

### Вариант B — на своём ПК (Windows)
1. Установите **Visual Studio 2022 Community** с нагрузкой «Разработка классических приложений на C++», а также **Git** и **CMake** (CMake ставится вместе с VS).
2. В папке проекта выполните:
   ```
   cmake -B build -G "Visual Studio 17 2022" -A x64
   cmake --build build --config Release
   ```
3. Готовый плагин: `build\FormantFlex_artefacts\Release\VST3\FormantFlex.vst3`.
   Там же лежит Standalone-версия: её можно запустить отдельно и проверить на микрофоне.

## Установка в FL Studio 25
1. Скопируйте папку `FormantFlex.vst3` в `C:\Program Files\Common Files\VST3\`.
2. В FL Studio откройте **Options → Manage plugins → Find installed plugins**.
3. В микшере выберите канал с вокалом, затем слот → **FormantFlex**.
   Совет: ставьте плагин **после** тюна/питч-коррекции и **до** реверба и дилея.

macOS: скопируйте `.vst3` в `~/Library/Audio/Plug-Ins/VST3/`. Если система блокирует неподписанный плагин, выполните
`xattr -dr com.apple.quarantine ~/Library/Audio/Plug-Ins/VST3/FormantFlex.vst3`.

## Быстрые рецепты
| Задача | FORMANT | DETAIL | MIX |
|---|---|---|---|
| Мужской → женский (вместе с Pitch +3…+5 в Pitcher/NewTone) | +3 … +5 | 50 % | 100 % |
| Женский → мужской (вместе с Pitch −3…−5) | −3 … −5 | 50 % | 100 % |
| Чуть «дороже» и плотнее голос | −1 … −2 | 40 % | 60–100 % |
| Монстр / злодей | −8 … −12 | 60 % | 100 % |
| Мультяшный / chipmunk-тембр | +7 … +12 | 50 % | 100 % |
| Даблы и бэки с другим тембром | ±2 … ±4 | 50 % | 100 % на дубле |

## Файлы
- `Source/FormantCore.h` — DSP-ядро без зависимостей (можно тестировать отдельно)
- `Source/PluginProcessor.*` — параметры, обработка, задержка, сохранение состояния
- `Source/PluginEditor.*` — интерфейс
- `tests/test_core.cpp` — тесты ядра (`g++ -O2 -std=c++17 tests/test_core.cpp -o t && ./t`)
